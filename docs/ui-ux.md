Document 4 — UX/UI Screen Specification
1. UX Design Principles

The application should be designed around the realities of a busy doctor's chamber.

Core principles
Consultation-first
The doctor should spend minimum time navigating the application.
Staff-first operations
Reception staff should handle appointments, registration, queue and payments.
Patient context everywhere
Important patient information should be accessible without repeatedly navigating away.
One-tap common actions
Start consultation, next patient, add vitals, previous prescription and AI summary should be highly accessible.
Bangla + English
UI language can be switched.
Clinical terminology can remain configurable.
Mobile-first
Doctor and staff workflows should work extremely well on mobile/tablet.
Desktop-friendly
Web/tablet interface should provide richer dashboards and reporting.
AI must be visually distinguishable
Users should immediately know which information was generated by AI.

46. AI UX Rules

AI components should always visually communicate:

AI Generated
✨ AI Generated
Requires Review
⚠ Review Required
Patient Data Used
Based on patient records
Final Clinical Decision

Only the doctor can explicitly approve.

This prevents users from confusing AI suggestions with official medical records.
